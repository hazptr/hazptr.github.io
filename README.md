# hazptr.github.io

Source for [hazptr.github.io](https://hazptr.github.io/). The page lists projects live from the GitHub API, so new public repos show up without a change here.

`site/assets/` holds the bubbles (`bubbles.js`), the page effects (`fx.js`) and the shared styles (`base.css`). The Neiro and Neiro extensions pages carry copies of them.
